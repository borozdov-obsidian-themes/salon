# Borozdov Salon

A theme from the Borozdov collection. Two faces — light **Matinee**, editorial ink on white
banded with mint cream, and dark **Soiree**, the same salon after hours. A sharp display
serif, warm black pills and one chartreuse highlighter for what matters.

![Borozdov Salon in light mode](https://raw.githubusercontent.com/borozdov-obsidian-themes/salon/main/screenshots/light.png)

![Borozdov Salon in dark mode](https://raw.githubusercontent.com/borozdov-obsidian-themes/salon/main/screenshots/dark.png)

## Principles

- **Two voices kept apart.** A sharp display serif only at the largest sizes: the title and
  the first heading in Spectral Light, stacked tight; every other heading and the text in
  the platform's grotesque, tracked in.
- **Printed ink.** A warm near-black ink rather than pure black; white paper banded with
  mint cream; flat surfaces separated by tint.
- **One chartreuse.** The main button, a checked task, a toggle, the open file and the
  highlighter; the plain note is a black card titled in chartreuse.
- **Pills and small cards.** Pill buttons in warm black, 8px cards and badges, 12px fields.

## Features

- Light and dark modes, following Settings → Appearance → Base color scheme
- Callouts as flat mint-cream cards; the plain note as a black card titled in chartreuse
- Pull quotes as editorial statements in the display serif
- Tags as mint-cream badges that turn chartreuse under the pointer
- Quiet editing: no focus ring around the note, its title or form fields while you type;
  property names read as labels, not boxed fields
- Text colours meet WCAG contrast on both faces
- The phone layout keeps the same colours and shapes
- No `!important`: every rule can be overridden with a CSS snippet

## Installation

**From the community directory:** Settings → Appearance → Themes → Manage, search for
**Borozdov Salon**, then **Install and use**.

**By hand:** download `manifest.json` and `theme.css` from the [latest
release](https://github.com/borozdov-obsidian-themes/salon/releases/latest) into
`<vault>/.obsidian/themes/Borozdov Salon/`, then choose Borozdov Salon under Settings →
Appearance → Themes.

## Font

Spectral Light (© 2017 The Spectral Project Authors) is embedded in `theme.css` as base64
WOFF2 under the SIL Open Font License 1.1 — see [`fonts/OFL.txt`](fonts/OFL.txt). One
weight, Latin and Cyrillic, for the title, the largest heading and pull quotes.
